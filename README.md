## 缺點與隱藏條款：下單前必看

條款層面，RackNerd 走的是「全預付、零彈性」路線，具體是這幾條：

- **任何情況下不退款。** 官方條款寫明 no refunds under any circumstance，VPS 促銷又是年付預繳，等於下單就綁一整年。想先試手感，共享主機月付是唯一的低風險入口。
- **到期即刪檔，且 VPS 沒有代管備份。** 服務一終止，資料立刻刪除，官方不會替你保留。自己做異地備份在這家是必做功課。
- SLA 的保固範圍比標題看起來窄：99.999% 針對網路連線與電力，不涵蓋機器硬體本身；賠償按額外停機時數以月費 2% 起算、上限 50%，且須在 30 天內提出。
- 約每 500 張訂單會有 1 張被抽中要求驗證身分。流程不麻煩，但急用的人要知道有這一關。
- 沒有即時客服。深夜出事只能等工單，即使平均回應多半在 10 分鐘以內。
- 帳單與伺服器管理分屬兩個入口：帳務在 WHMCS，伺服器操作在自家面板，剛上手要多適應一下。

負評也值得如實轉述。有用戶在週末只收到一封警告信，伺服器就被刪除且無備份可救；也有人遇到封包遺失，客服將原因歸到用戶本地 ISP。這些案例指向同一個教訓——別把唯一副本放在任何便宜 VPS 上。平心而論，Trustpilot 上所有負評官方都回了，Reddit 的批評公司帳號也會正面接招，態度沒得挑剔，硬的是條款本身。
